# Prevenção de Incêndio — CBPMESP | Estudo Interativo

Site estático para GitHub Pages.

Inclui teoria organizada por temas, 60 questões de múltipla escolha, justificativa da alternativa clicada, explicação da correta quando houver erro, progresso, pontuação, busca na teoria, resumo de memorização e questões de cálculo.

Fonte principal: Revisão Geral de Prevenção de Incêndios fornecida pelo usuário.
Apoio: Apostila de Prevenção de Incêndios, Resumo e Puro Suco do Milho.

Publicação: envie `index.html` para a branch `main` do GitHub e ative Settings → Pages → Deploy from a branch → main → /(root).
