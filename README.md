# Prevenção de Incêndio — CBPMESP | Estudo Interativo

Site estático para GitHub Pages.

Inclui teoria organizada por temas, 141 questões de múltipla escolha, justificativa didática de cada alternativa clicada, explicação da correta quando houver erro, referência da página da Apostila, progresso, pontuação, busca na teoria e resumo de memorização.

Fonte principal: Revisão Geral de Prevenção de Incêndios fornecida pelo usuário.
Apoio: Apostila de Prevenção de Incêndios, Resumo e Puro Suco do Milho.

Publicação: envie `index.html` para a branch `main` do GitHub e ative Settings → Pages → Deploy from a branch → main → /(root).


## Conteúdo atual
- 20 aulas teóricas expansíveis
- 141 questões comentadas
- Referência da página da Apostila em cada questão
- Sem questões de cálculo numérico; a fórmula N=P/C é cobrada apenas conceitualmente

## Novidades da versão de navegação e progresso
- Navegador numerado das questões, permitindo ir diretamente para qualquer questão.
- Salvamento automático no navegador (`localStorage`) após respostas, navegação e marcações.
- Ao voltar ao site no mesmo navegador/dispositivo, o aluno pode continuar de onde parou.
- Indicadores visuais para questão atual, acertos, erros, não respondidas e questões marcadas para revisão.
- Modos "Revisar erros" e "Marcadas".
- Atalho para a próxima questão ainda não respondida.
- Botão para limpar o progresso salvo e recomeçar.

**Observação:** o progresso é salvo localmente no navegador/dispositivo. Não existe login nem sincronização entre computadores ou celulares.

## Teoria
As referências de IT foram retiradas dos subtítulos das aulas para evitar repetição visual. As ITs continuam mencionadas no conteúdo quando são necessárias para o entendimento do assunto ou aparecem nas questões.
